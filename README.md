Lifestyle super-app: **Whistle** social, Circles, Space, Pay, Ask Aura (Google Search + Gemini).

https://sahanvaibhav.github.io/aura-whistle/

## Google setup (Gmail + Google Search)

1. Open the app → **Me → API & Google settings**
2. Paste OAuth Web Client ID, Custom Search API key + CX, optional Gemini key
3. Google Cloud → Credentials → OAuth client → Authorized JavaScript origins:
   - https://sahanvaibhav.github.io
4. Enable Custom Search API. Create CX at https://programmablesearchengine.google.com

Keys stay in browser localStorage only.
